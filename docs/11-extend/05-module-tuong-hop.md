# 05. Module Tương Hợp

Mở file này khi cần so khớp hai lá số cho hợp tác, hôn nhân, hoặc tử tức.

## Bao gồm

- Mục đích module 4
- Các loại so khớp
- Thuật toán compatibility

## Khi nào dùng

- Khi so khớp đối tác kinh doanh
- Khi so khớp hôn nhân
- Khi phân tích tương quan tử tức

## Các loại so khớp

- Hợp tác kinh doanh
- Hôn nhân
- Tử tức

## Đầu vào bổ sung

Module này cần `partnerChart`, nên trong API tổng hợp chỉ chạy khi có lá số đối tác.

## Ghi nhớ

- Nếu request không có `partnerChart`, module này không nên chạy.
