# 06. Module Thời Điểm Đại Lợi

Mở file này khi cần chọn thời điểm tốt theo lá số, Can Chi, và vận hạn.

## Bao gồm

- Mục đích module 5
- Thuật toán auspicious timing

## Khi nào dùng

- Khi cần chọn ngày giờ tốt
- Khi cần gợi ý tháng tốt, ngày tốt, giờ tốt
- Khi kết hợp với quyết định công việc lớn

## Trọng tâm module

- Dựa trên `Can Chi`
- Dựa trên `ngũ hành`
- Dựa trên `minor fate`
- Loại trừ các thời điểm xung hoặc bất lợi

## Ghi nhớ

- Đây là module tối ưu thời điểm, không phải module dự báo biến cố.
