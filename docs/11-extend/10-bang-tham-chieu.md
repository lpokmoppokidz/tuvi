# 10. Bảng Tham Chiếu Nhanh

Mở file này khi cần tra cứu nhanh ký hiệu, ngũ hành, hoặc Can Chi.

## Bao gồm

- Ký hiệu viết tắt
- Ngũ hành tương sinh / tương khắc
- Bảng Can Chi

## Khi nào dùng

- Khi đọc thuật toán
- Khi viết code và cần tra lại thuật ngữ
- Khi review output nhanh

## Các mục chính

- `PalaceData`
- `Tứ Mộ`
- `Tứ Linh`
- `Lục Tài`
- `Tứ Sát`
- `Lục Bại`
- `Tam Hóa`
- `Trúc La`
- `Lục Hành Xung`
- `Tứ Hành Xung`
- `Lục Hợp`
- `Đối Xung`
- `Đại hạn`
- `Tiểu hạn`

## Ghi nhớ

- Đây là file phụ trợ cuối cùng, không phải file đọc đầu tiên.
