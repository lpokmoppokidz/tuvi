# 04. Module Sức Khỏe

Mở file này khi cần hệ thống cảnh báo sức khỏe theo lá số.

## Bao gồm

- Mục đích module 3
- Bảng ánh xạ sao sang cơ quan và bệnh lý
- Thuật toán phân tích sức khỏe

## Khi nào dùng

- Khi muốn cảnh báo sớm về cơ quan yếu
- Khi muốn theo dõi rủi ro theo tuổi hoặc hạn
- Khi cần kết hợp với module Crisis Alert

## Trọng tâm module

- Xét `Tật Ách` và các cung liên quan
- Ánh xạ sao sang nhóm bệnh/cơ quan
- Chấm mức độ nguy cơ
- Đưa ra cảnh báo và khuyến nghị theo dõi

## Ghi nhớ

- Đây là module cảnh báo, không thay cho chẩn đoán y khoa.
