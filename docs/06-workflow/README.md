# Workflow Notes

Thư mục này gom các tài liệu vận hành nội bộ để giảm nhiễu ở thư mục gốc.

## Nội dung

- `TASK.md`: phạm vi và trạng thái phiên làm việc hiện tại
- `session-log.md`: quyết định kỹ thuật và ghi chú ngắn theo phiên

## Ghi chú

- Các file convention cho agent như `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` vẫn được giữ ở root để không phá toolchain.
- File script tiện ích nên nằm trong `scripts/` thay vì đặt rời ở root.
