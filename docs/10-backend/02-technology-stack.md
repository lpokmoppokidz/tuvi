# 02. Technology Stack

Mở file này khi cần xem công nghệ backend, frontend liên quan, công cụ phát triển, và lý do chọn Supabase.

## Bao gồm

- Backend stack
- Frontend stack liên quan
- Development tools
- So sánh Supabase với tự build backend

## Khi nào dùng

- Khi cần quyết định công nghệ
- Khi setup môi trường
- Khi cần justify vì sao dùng Supabase

## Backend stack

- `Supabase / PostgreSQL 15+`
- `Supabase Auth`
- `Supabase Edge Functions (Deno 2.x)`
- `Supabase Realtime`
- `Supabase Storage`
- `Resend / Edge Email`
- `pgvector`

## Frontend stack liên quan

- `React Native Expo SDK 54`
- `Expo Router v6`
- `Redux Toolkit`
- `TypeScript`

## Development tools

- `Supabase CLI`
- `Deno`
- `Postman / Insomnia`
- `pgAdmin`
- `GitHub Actions`

## Supabase vs tự build

File gốc chốt khuyến nghị dùng `Supabase` vì:

- Setup nhanh
- Có auth, database, storage sẵn
- Free/Pro tier phù hợp MVP
- Edge Functions đủ mạnh cho bài toán Tử Vi
- Có đường nâng cấp hoặc migrate sau này

## Ghi nhớ

- Nếu team đang tranh luận về platform backend, đây là file cần mở trước.
