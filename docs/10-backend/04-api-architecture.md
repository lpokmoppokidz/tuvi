# 04. API Architecture

Mở file này khi cần xem các endpoint backend, nhóm API, và ví dụ request/response.

## Bao gồm

- API endpoints overview
- REST endpoints theo nhóm
- Request/response examples

## Khi nào dùng

- Khi thiết kế contract giữa mobile và backend
- Khi viết service layer frontend
- Khi test API bằng Postman hoặc Insomnia

## Nhóm API chính

- Authentication APIs
- Horoscope APIs
- Vận Hạn APIs
- Interpretation APIs
- User APIs
- Subscription APIs

## Endpoint nổi bật

- `POST /functions/v1/calculate`
- `POST /functions/v1/van-han/calculate`
- Các endpoint lấy lá số, timeline vận hạn, chia sẻ lá số

## Ghi nhớ

- Nếu team frontend hỏi “gọi API nào”, mở file này.
- Nếu cần xem auth và security quanh API, chuyển sang `05-auth-va-security.md`.
