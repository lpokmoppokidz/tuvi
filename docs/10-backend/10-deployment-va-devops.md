# 10. Deployment Và DevOps

Mở file này khi cần setup Supabase CLI, migration, deploy Edge Functions, hoặc CI/CD.

## Bao gồm

- Supabase CLI setup
- Database migration
- Edge Functions deployment
- GitHub Actions CI/CD

## Khi nào dùng

- Khi bắt đầu triển khai project backend
- Khi cần quy trình deploy chuẩn
- Khi setup CI/CD pipeline

## Các lệnh chính

- `supabase init`
- `supabase link`
- `supabase migration new`
- `supabase db push`
- `supabase functions deploy`

## Ghi nhớ

- File này là nơi mở khi muốn đưa backend từ local lên cloud.
