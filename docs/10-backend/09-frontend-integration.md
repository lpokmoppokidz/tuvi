# 09. Frontend Integration

Mở file này khi cần biết app mobile tích hợp với backend Supabase như thế nào.

## Bao gồm

- Supabase client setup
- Auth helpers
- Horoscope service
- Vận Hạn service
- Redux integration

## Khi nào dùng

- Khi nối app với backend
- Khi viết service layer frontend
- Khi tổ chức async thunk hoặc state cho horoscope/van han

## Các phần chính

- `supabase` client
- `signUp`, `signIn`, `signOut`, `getCurrentUser`
- `horoscopeService`
- `vanHanService`
- Redux slice cho horoscope

## Ghi nhớ

- Nếu cần contract API, đọc kèm `04-api-architecture.md`.
