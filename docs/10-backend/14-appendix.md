# 14. Appendix

Mở file này khi cần bảng tra cứu nhanh, sample seed, hoặc environment variables.

## Bao gồm

- Bảng Can Chi
- Bảng Ngũ Hành
- Bảng Tương Sinh/Tương Khắc
- Bảng Độ Sáng Sao
- Sample database seed note
- Environment variables

## Khi nào dùng

- Khi cần tra cứu nhanh
- Khi viết script seed
- Khi setup môi trường local hoặc production

## Environment variables chính

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `STRIPE_SECRET_KEY`
- `STRIPE_WEBHOOK_SECRET`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- `NEXT_PUBLIC_APP_URL`

## Ghi nhớ

- Đây là file phụ trợ cuối cùng, không phải file đọc đầu tiên.
