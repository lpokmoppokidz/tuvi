# 13. Roadmap

Mở file này khi cần xem kế hoạch triển khai theo phase.

## Bao gồm

- Phase 1: Setup & Core
- Phase 2: Algorithm Engine
- Phase 3: Vận Hạn Engine
- Phase 4: API & Frontend Integration
- Phase 5: Polish & Launch

## Khi nào dùng

- Khi cần chia sprint
- Khi planning backlog
- Khi báo tiến độ theo milestone

## Các phase

### Phase 1

- Tạo Supabase project
- Chạy migrations
- Seed data
- Setup CLI
- Deploy functions cơ bản

### Phase 2

- Implement lunar calendar
- Implement Can Chi, Mệnh, Cục
- Implement 12 cung và sao
- Unit tests

### Phase 3

- Implement Đại/Tiểu/Nguyệt hạn
- Implement Cửu Phi Tinh
- Implement scoring engine
- Integration tests

### Phase 4

- Hoàn thiện API
- Tích hợp React Native
- Setup Redux
- Hoàn thiện các màn hình chính

### Phase 5

- Review RLS
- Tối ưu performance
- Caching
- Error handling
- Documentation
- Soft launch
