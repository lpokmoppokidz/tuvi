# 12. Cost Estimation

Mở file này khi cần ước tính chi phí backend và kế hoạch scale.

## Bao gồm

- Supabase pricing
- Ước tính chi phí MVP và production
- Scaling path

## Khi nào dùng

- Khi lên budget
- Khi quyết định tier Supabase
- Khi chuẩn bị scale hệ thống

## Các mức chính

- `Free`
- `Pro`
- `Team`

## Kết luận từ tài liệu gốc

- MVP có thể chạy ở mức khoảng `25 USD/tháng`
- Production có thể ở mức `25-100 USD/tháng`

## Ghi nhớ

- Nếu cần tradeoff kỹ thuật và chi phí, đọc file này cùng `02-technology-stack.md`.
