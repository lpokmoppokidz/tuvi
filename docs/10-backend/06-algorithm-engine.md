# 06. Algorithm Engine

Mở file này khi cần xem backend xử lý thuật toán lá số và vận hạn như thế nào.

## Bao gồm

- Core algorithm modules
- Chi tiết các bước tính
- Scoring và interpretation engine

## Khi nào dùng

- Khi thiết kế engine tính toán
- Khi tách logic sang Edge Functions hoặc module dùng chung
- Khi debug kết quả tính lá số hoặc vận hạn

## Các module chính

- Lunar Date Conversion
- Can Chi Calculator
- Mệnh Calculator
- Cục Số Calculator
- An 12 Cung
- An Sao Cố Định
- Tính Vận Hạn
- Cửu Phi Tinh
- Scoring & Interpretation Engine

## Ghi nhớ

- Đây là phần nặng nhất về nghiệp vụ.
- Nếu cần nơi thực thi thuật toán trên Supabase, đọc tiếp `07-edge-functions.md`.
